## Learning Path

A practical progression through this collection is:

1. Begin with **Vengeance Discovery Lab** to establish discovery and reconnaissance concepts.
2. Continue with **Vengeance Recon Trail** for additional reconnaissance practice.
3. Study **Vengeance User Trust: Broken Paths** to explore access-control and path-related security concepts.
4. Move to **Venus File Shuttle** for file-discovery practice.
5. Explore **Venus Cookie SSH Root** for SSH and privileged-access concepts.
6. Study **Venus PwnKit Prep Lab** before the PwnKit-focused exercises.
7. Continue with **Venus PwnKit Breakout** and **PwnKit on Venus**.
8. Practice **Venus LinPEAS Escalation** for Linux privilege-escalation enumeration.
9. Finish with **Venus Post-Exploitation Trails**, **Venus Root Drift**, and **Venus Root Flag Trail**.

Adapt the sequence according to your existing Linux and cybersecurity knowledge.

## How to Use the Labs

1. Select a lab from the index.
2. Open its direct Learn SecByte URL.
3. Review the lab objectives and authorized scope.
4. Work only inside the provided CTF or training environment.
5. Record the security concepts and findings you encounter.
6. Focus on understanding the underlying weakness rather than simply reproducing commands.
7. Consider how the relevant issue could be detected, prevented, or remediated.

For penetration testing learners, useful notes include the initial access condition, security boundary involved, enumeration observations, privilege boundary, and defensive controls.
